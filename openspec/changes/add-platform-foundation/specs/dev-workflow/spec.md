# Spec Delta: dev-workflow

## Purpose

Gives developers and agents one-command workflows (start, index, query, evaluate, test, lint, load) through a root Makefile, a documented environment file, a shared lint configuration and a pinned model-digest lock.

## ADDED Requirements

### Requirement: Root Makefile targets
The repository SHALL provide a root `Makefile` with the targets `doctor`, `models`, `models-lock`, `up`, `down`, `clean`, `index`, `query`, `eval`, `eval-record-ci`, `eval-ci`, `snapshot`, `snapshot-restore`, `test`, `lint` and `load`, each running the command defined in foundation design contract C10.

#### Scenario: Targets listed
- **WHEN** a developer runs `make help`
- **THEN** every target above is listed with a one-line description

#### Scenario: Test and lint tolerate missing packages
- **WHEN** `make test` or `make lint` runs while some of `indexer/`, `reranker/`, `evals/`, `service/` have no build file yet
- **THEN** the missing packages are skipped with a message and the target exits 0 if the present packages pass

### Requirement: Documented environment
The repository SHALL provide `.env.example` containing every variable in contract C2 with working local defaults, and SHALL never commit `.env`.

#### Scenario: Copy and run
- **WHEN** a developer runs `cp .env.example .env && make up` without editing values
- **THEN** the stack starts with the default credentials and ports

### Requirement: Pinned model digests
The repository SHALL provide `infra/models.lock.json` recording the Ollama digests of `bge-m3` and `llama3.1:8b` and the reranker model revision, regenerated by `make models-lock` from the live Ollama `/api/tags` endpoint and the Hugging Face model API.

#### Scenario: Lock regenerated from live models
- **WHEN** `make models-lock` runs with both models pulled
- **THEN** `infra/models.lock.json` contains 64-hex digests equal to those reported by `ollama list` for both models

### Requirement: Environment self-check
`make doctor` SHALL report, with a pass/fail line each, whether Docker is running, `.env` exists, Ollama is reachable, both models are pulled, `uv` is installed and a JDK of version 21 or later is available, and SHALL exit non-zero if any check fails.

#### Scenario: Ollama down
- **WHEN** `make doctor` runs while Ollama is not running
- **THEN** it prints a failing line for Ollama reachability and exits non-zero

### Requirement: Shared Python lint rules
The repository SHALL provide a root `ruff.toml` (Python 3.12 target, line length 100) that every Python package extends.

#### Scenario: Package extends root config
- **WHEN** a Python package's ruff configuration is inspected
- **THEN** it extends `../ruff.toml`
